Entry for the [make.fun bounty "One Line, Zero Use: The Useless Superpower Sprint"](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68).

`main.py` writes one short text to `/output/entry.txt` — a hilariously
useless superpower: hearing a mosquito anywhere in the house, but only
once you've fallen asleep, and only loud enough to keep you awake. The
power is real; its only use is torment.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (UTF-8, 118 characters).
The program is deterministic: running it twice writes exactly the same bytes.
It needs no network access and no dependencies beyond Python 3 stdlib.
